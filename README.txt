طابعة الستكرات
==============

التشغيل السريع (يلزم Python على ويندوز):
    run.bat

لإنشاء ملف exe مستقل:
    build_exe.bat
    (الناتج: dist\StickerPrinter.exe)

أو ارفع المجلد إلى GitHub وشغّل Build Windows EXE من تبويب Actions، ثم نزّل StickerPrinter-Portable: مجلد محمول (exe واحد، لا تثبيت ولا أدمن، والإعدادات تُحفظ بجانبه).

طريقة الاستعمال:
1) اختر ملف الإكسل (الصف الأول = عناوين الأعمدة). جرّب sample.xlsx
2) اختر أعمدة النص، وعمود QR، وعمود عدد النسخ (اختياري)
3) اضبط عرض وارتفاع الملصق بالمليمتر
4) اختر الطابعة ثم اضغط «طباعة ملصق تجريبي» قبل الطباعة الكاملة
5) إن كان الملصق مزاحاً قليلاً عدّل الإزاحة الأفقية/الرأسية

ملاحظة: لخط مخصص ضع font.ttf و font-bold.ttf بجانب البرنامج.
